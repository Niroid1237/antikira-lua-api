Antikira Lua API

Antikira ships with a built-in LuaJIT runtime, ffi support, script management in the menu, and a documented in-process API for callbacks, rendering, entity access, user commands, game events, and config values.

LuaJIT Runtime FFI Support Drawing API Entity Access Config R/W Event System

Getting Started

Quick start guide for writing Lua scripts with Antikira.

Runtime: Antikira uses LuaJIT, not stock Lua 5.1 or Lua 5.4. Scripts can use local ffi = ffi or require("ffi").

Scripts Folder

Scripts are loaded from C:\Antikira\scripts. On first initialization the runtime creates example.lua automatically.

Menu Workflow

Open the cheat menu and go to SCRIPTS. Actions: Refresh, Open folder, Load, Unload, Reload.

First Script
example.lua
register_callback("draw", function()
    render.text(20, 20, "hello from lua", color_t(1.0, 1.0, 1.0, 1.0), 12)
end)
Event Example
event.lua
register_callback("player_hurt", function(event)
    local victim = event:get_player_pawn("userid")
    if victim and victim:is_valid() then
        antikira.notify("hurt: " .. victim:get_name())
    end
end)
Create Move Example
create_move.lua
register_callback("create_move", function(cmd)
    if cmd:has_button(buttons.IN_JUMP) then
        cmd:add_button(buttons.IN_DUCK)
    end
end)
Config Example
config.lua
config.set_bool("m_enabled_autostrafe", true)
config.set_int("m_autostrafe_mode", 1)
config.set_int("m_autostrafe_boost", 100)
config.set_int("m_hitchance_awp", 70)

Runtime

How the LuaJIT runtime works inside Antikira.

Engine: Antikira embeds LuaJIT. This gives you ffi support and makes most public CS2 Lua snippets easier to adapt.

Script Loading

Scripts are loaded from C:\Antikira\scripts. The runtime creates the directory if missing, creates example.lua on first init, keeps one Lua state per loaded script, and destroys it on unload.

Package Search Paths

Antikira appends script-local paths to Lua's package search path:

  • C:\Antikira\scripts\?.lua
  • C:\Antikira\scripts\?\init.lua
  • C:\Antikira\scripts\?.dll

Error Behavior

If a callback throws: the error is logged, an in-game notification is shown, and the current callback invocation stops. The script is not deleted.

FFI

ffi is exposed globally if LuaJIT can load it: local ffi = ffi or require("ffi")

Runtime Example
runtime.lua
local ffi = ffi or require("ffi")

register_callback("draw", function()
    local name = environment.script_name()
    render.text(20, 20, "loaded: " .. name, color_t(0.9, 0.9, 0.9, 1.0), 12)
end)

Callbacks

Main integration point between Lua and the cheat runtime.

register_callback(name, fn)

Registers a callback for the current script.

name - callback name (string)
fn - Lua function
register_callback("draw", function()
    render.text(20, 20, "hello", color_t(1.0, 1.0, 1.0, 1.0), 12)
end)
unregister_callback(name)

Removes a previously registered callback for the current script.

callbacks.register / callbacks.unregister

Aliases for the global register_callback and unregister_callback.

Built-In Constants

callbacks.DRAW callbacks.PAINT callbacks.CREATE_MOVE callbacks.EVENT callbacks.SHUTDOWN callbacks.MENU

Supported Callback Kinds

Paint / Draw

Names: "draw", "paint". Use for text, lines, boxes, indicators, debug overlays.

Create Move

Name: "create_move". Arguments: cmd. Use for input modification, button changes, movement helpers, angle edits.

Generic Event

Name: "event". Arguments: event. Receives every incoming game event.

Specific Game Event

Any exact event name such as "player_hurt", "round_start", "item_purchase". Arguments: event.

Shutdown

Name: "shutdown". Use to clean up state before the script is unloaded.

Menu

Name: "menu". Use to build custom UI widgets in the SCRIPTS tab. Widget functions like menu.checkbox, menu.slider_int, etc. are only available inside this callback.

Normalized Names: "draw" and "paint" both map to paint. "createmove" and "create_move" both map to movement. Using constants avoids typos.
Replacement: Registering the same callback name again replaces the previous function for that name.

Module: antikira

Utility functions owned by the runtime itself.

antikira.log(text)

Writes a log line prefixed as Lua output in the cheat log.

text - string
antikira.log("hello from lua")
antikira.notify(text)

Shows an in-game notification through the overlay notification system.

text - string
antikira.notify("script loaded")
antikira.script_name() -> string

Returns the current script file name without the .lua extension.

antikira.log("current script: " .. antikira.script_name())

Module: globals

Alias: global_vars. Engine timing and shared state helpers.

globals.curtime() -> number

Returns engine curtime.

globals.realtime() -> number

Returns engine real time.

globals.frametime() -> number

Returns current frame time.

globals.tickcount() -> integer

Returns current engine tick count.

globals.map_name() -> string

Returns current map name. If no map is active, returns empty string.

globals.screen_size() -> number, number

Returns screen_w and screen_h.

Example 
register_callback("draw", function()
    local map = globals.map_name()
    local tick = globals.tickcount()
    render.text(20, 20, ("map=%s tick=%d"):format(map, tick), color_t(1.0, 1.0, 1.0, 1.0), 12)
end)

Module: engine

Client engine helpers.

engine.is_in_game() -> boolean

Returns whether the engine is currently in a game session.

engine.is_connected() -> boolean

Returns whether the client is connected.

engine.execute_cmd(cmd)

Executes a client command through the unrestricted client command path.

Aliases: engine.exec(cmd), engine.execute_client_cmd(cmd)
engine.execute_cmd("say hello from lua")
engine.get_level_name() -> string

Returns the current map name. Alias for globals.map_name().

Module: entitylist

Entity lookup helpers.

entitylist.get_local_pawn() -> entity|nil

Returns the local player pawn if available.

entitylist.get_local_controller() -> entity|nil

Returns the local player controller if available.

entitylist.get_highest_index() -> integer

Returns the current highest entity index reported by the entity system.

entitylist.get_entity(index) -> entity|nil

Returns the entity for a raw entity index.

index - integer entity index
entitylist.get_players() -> table

Returns an array-style Lua table of player pawns. Invalid/missing players skipped. Indexes are compacted from 1.

for i, player in ipairs(entitylist.get_players()) do
    if player:is_valid() and player:is_alive() then
        antikira.log(player:get_name())
    end
end

Module: render

Alias: imgui. Immediate drawing helpers backed by the ImGui background draw list.

Color Input: Every drawing function supports two forms: integer RGBA (255, 255, 255, 255) or color_t(1.0, 1.0, 1.0, 1.0) with normalized 0.0..1.0 values.
render.screen_size() -> number, number

Returns screen_w, screen_h. Alias: render.get_screen_size().

render.text(x, y, text, color[, size])

Draws text on the background draw list. Optional size (default: medium font legacy size).

render.line(x1, y1, x2, y2, color[, thickness])

Draws a line.

render.rect(x, y, w, h, color[, rounding[, thickness]])

Draws an outlined rectangle.

render.rect_filled(x, y, w, h, color[, rounding])

Draws a filled rectangle.

render.circle(x, y, radius, color[, segments[, thickness]])

Draws an outlined circle. Default segments: 32.

render.circle_filled(x, y, radius, color[, segments])

Draws a filled circle. Default segments: 32.

render.world_to_screen(x, y, z) -> boolean, number, number

Returns visible, screen_x, screen_y. Alias: math.world_to_screen(x, y, z).

Render Example 
register_callback("draw", function()
    local local_pawn = entitylist.get_local_pawn()
    if not local_pawn or not local_pawn:is_valid() then return end

    local x, y, z = local_pawn:get_origin()
    local visible, sx, sy = render.world_to_screen(x, y, z + 72.0)
    if visible then
        render.circle_filled(sx, sy, 4, color_t(0.2, 1.0, 0.4, 1.0), 24)
        render.text(sx + 8, sy - 6, local_pawn:get_name(), color_t(1.0, 1.0, 1.0, 1.0), 12)
    end
end)

Module: menu

Menu state helpers and custom script UI widgets.

Menu Callback: Use register_callback("menu", fn) to build custom UI for your script. Widget functions only work inside a "menu" callback.

Menu State

menu.is_open() -> boolean

Returns whether the Antikira menu is currently open.

menu.get_pos() -> number, number

Returns x, y — menu window top-left position.

menu.get_size() -> number, number

Returns w, h — current menu window size.

Custom Script UI Widgets

These functions create interactive UI widgets in the script's menu section. They only work inside a register_callback("menu", fn) callback. Widgets bind directly to existing config variables by their internal name.

menu.checkbox(label, var_name) -> boolean

Creates a checkbox bound to a bool config variable.

label - display text
var_name - name of a bool config variable

Returns true if the value was toggled this frame.

menu.slider_int(label, var_name, min, max) -> boolean

Creates an integer slider bound to an int config variable.

label - display text
var_name - name of an int config variable
min - minimum value
max - maximum value

Returns true if the value was changed this frame.

menu.slider_float(label, var_name, min, max) -> boolean

Creates a float slider bound to a float config variable.

label - display text
var_name - name of a float config variable
min - minimum value
max - maximum value

Returns true if the value was changed this frame.

menu.combo(label, var_name, items) -> boolean

Creates a combo box bound to an int config variable.

label - display text
var_name - name of an int config variable
items - Lua table of string options {"A", "B", "C"}

Returns true if the selection changed this frame.

menu.button(label) -> boolean

Creates a clickable button.

label - button text

Returns true if the button was clicked this frame.

menu.label(text)

Draws static label text.

text - label text
menu.color_picker(id, var_name) -> boolean

Creates a color picker bound to a hellcolor config variable.

id - unique identifier for the picker
var_name - name of a hellcolor config variable

Returns true if the color was changed this frame.

menu.same_line([offset])

Places the next widget on the same line.

offset - optional offset from start (default 0)
menu.separator()

Draws a horizontal separator line.

menu.new_line()

Inserts a blank line.

Example Script Menu

Script with Custom Menu 
register_callback("menu", function()
    menu.checkbox("Auto Strafe", "m_enabled_autostrafe")
    menu.same_line()
    if menu.button("Toggle Watermark") then
        config.toggle_bool("m_enabled_watermark")
    end

    menu.separator()

    menu.label("Hitchance")
    menu.slider_int("AWP", "m_hitchance_awp", 0, 100)
    menu.slider_int("Scout", "m_hitchance_scout", 0, 100)

    menu.separator()

    menu.combo("Autostrafe Mode", "m_autostrafe_mode", {"Off", "Directional", "Rage"})
    menu.slider_int("Boost", "m_autostrafe_boost", 0, 100)
end)

Module: environment

Script path helpers.

environment.scripts_path() -> string

Returns the scripts directory path: C:\Antikira\scripts

environment.script_path() -> string

Returns the full path of the current script file.

environment.script_name() -> string

Returns the current script name. Same as antikira.script_name().

Example 
antikira.log("scripts folder: " .. environment.scripts_path())

Module: config

Direct access to existing Antikira config variables from Lua.

Important: Names are exact internal C++ variable names from Antikira/src/cheat/config/vars.h. Lua indexes are 1-based. Current support: bool, int, float, hellcolor, std::vector<bool>, std::vector<int>.

Discovery

config.has(name) -> boolean

Returns whether a config variable exists.

config.get_type(name) -> string

Returns type: "bool", "int", "float", "hellcolor", "std::vector<bool>", "std::vector<int>".

config.list([type_name]) -> table

Returns array-style table of all known config variable names. Filtered by type if type_name passed.

Bool Access

config.get_bool(name) / set_bool(name, value) / toggle_bool(name) -> boolean 
config.set_bool("m_enabled_autostrafe", true)
local new_state = config.toggle_bool("m_enabled_watermark")

Int Access

config.get_int(name) / set_int(name, value) -> integer 
config.set_int("m_autostrafe_mode", 1)
config.set_int("m_hitchance_awp", 70)

Float Access

config.get_float(name) / set_float(name, value) -> number 
config.set_float("m_bar_glow_intensity", 1.5)

Color Access

config.get_color(name) / set_color(name, r, g, b, a | color) -> color 
local c = config.get_color("m_enemy_glow_color")
config.set_color("m_enemy_glow_color", color_t(1.0, 0.15, 0.15, 1.0))
config.set_color("m_world_color", 255, 200, 200, 255)

Vector Access

config.get_bool_at(name, index) / set_bool_at(name, index, value)

Known m_removals indexes: 1=scope, 2=local name, 3=team names, 4=smoke, 5=flash, 6=legs, 7=aimpunch.

config.set_bool_at("m_removals", 4, true)
config.set_bool_at("m_removals", 5, true)
config.get_int_at(name, index) / set_int_at(name, index, value)

For flat std::vector<int> config values.

Practical Examples

Autostrafe 
config.set_bool("m_enabled_autostrafe", true)
config.set_int("m_autostrafe_mode", 1)
config.set_int("m_autostrafe_boost", 100)
Hitchance 
config.set_int("m_hitchance_awp", 72)
config.set_int("m_hitchance_scout", 68)
config.set_int("m_hitchance_ar", 55)
Error Behavior: The runtime raises a Lua error if you use an unknown variable name, call a getter/setter with the wrong type, or use an out-of-range vector index.

Module: buttons

Bitmask constants for the cmd object used inside "create_move" callbacks.

buttons.IN_ATTACK buttons.IN_ATTACK2 buttons.IN_JUMP buttons.IN_DUCK buttons.IN_FORWARD buttons.IN_BACK buttons.IN_USE buttons.IN_MOVELEFT buttons.IN_MOVERIGHT buttons.IN_SPEED buttons.IN_WALK buttons.IN_RELOAD buttons.IN_SCORE buttons.IN_ZOOM buttons.IN_SPRINT
Note: buttons.IN_WALK is a compatibility alias and maps to the same bit as IN_SPEED.
Buttons Example 
register_callback("create_move", function(cmd)
    if cmd:has_button(buttons.IN_JUMP) then
        cmd:add_button(buttons.IN_DUCK)
    end
end)

Object: entity

Entity objects returned by entitylist and event helpers.

Validity: Always guard dynamic entities: if not pawn or not pawn:is_valid() then return end
entity:is_valid() -> boolean

Returns whether the entity reference still resolves to a valid entity.

entity:get_index() -> integer

Returns the stored entity index.

entity:get_address() -> integer

Returns the raw entity pointer as integer (for debugging/ffi).

entity:get_class_name() -> string

Returns the class name if available, otherwise empty string.

entity:get_origin() -> number, number, number

Returns world origin. Returns nil if no scene node.

entity:get_velocity() -> number, number, number

Returns absolute velocity. Returns nil if entity does not resolve.

entity:get_health() -> integer

Returns health or 0.

entity:get_team() -> integer

Returns team number or 0.

entity:is_alive() -> boolean

For player pawns uses pawn-specific check. For non-pawns falls back to health > 0.

entity:is_scoped() -> boolean

Returns whether a player pawn is scoped. Non-player entities return false.

entity:get_eye_position() -> number, number, number

Returns eye position for a player pawn. Non-player entities return nil.

entity:get_name() -> string

Controller: player name. Pawn: resolves controller. Other types: class name fallback.

entity:get_controller() -> entity|nil

Pawn returns its controller. Controller returns itself. Other types return nil.

entity:get_pawn() -> entity|nil

Controller returns its pawn. Pawn returns itself. Other types return nil.

entity:is_enemy() -> boolean

Returns enemy state for player pawn/controller references. Unrelated entities return false.

entity:get_active_weapon() -> entity|nil

Returns the active weapon entity for a player pawn.

entity:get_weapon_name() -> string

If weapon, returns weapon data name. Otherwise empty string.

entity:get_steamid() -> integer

Returns SteamID for controllers and pawns. Otherwise returns 0.

Entity Example 
register_callback("draw", function()
    local players = entitylist.get_players()
    for i = 1, #players do
        local player = players[i]
        if player:is_valid() and player:is_alive() and player:is_enemy() then
            local x, y, z = player:get_origin()
            local visible, sx, sy = render.world_to_screen(x, y, z + 72.0)
            if visible then
                render.text(sx, sy, player:get_name(), color_t(1.0, 0.25, 0.25, 1.0), 12)
            end
        end
    end
end)

Object: cmd

cmd objects are passed into the "create_move" callback.

cmd:get_forward_move() / set_forward_move(value) -> number

Read/write forward move value.

cmd:get_side_move() / set_side_move(value) -> number

Read/write side move value.

cmd:get_up_move() / set_up_move(value) -> number

Read/write up move value.

cmd:get_view_angles() -> number, number, number

Returns pitch, yaw, roll. Returns nil if no view-angle buffer.

cmd:set_view_angles(pitch, yaw[, roll])

Writes new view angles. If roll omitted, 0.0 is used.

cmd:get_buttons() / has_button(mask) / add_button(mask) / remove_button(mask)

Button bitmask operations. Use masks from buttons module.

Cmd Example 
register_callback("create_move", function(cmd)
    if cmd:has_button(buttons.IN_JUMP) then
        cmd:add_button(buttons.IN_DUCK)
    end

    local pitch, yaw, roll = cmd:get_view_angles()
    if pitch then
        cmd:set_view_angles(pitch, yaw + 1.0, roll)
    end
end)

Object: event

Event objects passed into "event" and event-specific callbacks.

event:get_name() -> string

Returns the event name.

event:get_bool(key) -> boolean

Reads a boolean event field.

event:get_int(key) -> integer

Reads an integer event field.

event:get_float(key) -> number

Reads a float event field.

event:get_uint64(key) -> number

Reads unsigned 64-bit event field as Lua number.

event:get_string(key) -> string

Reads a string event field.

event:get_player_pawn(key) -> entity|nil

Resolves event player field as a pawn. Common keys: "userid", "attacker", "assister".

event:get_player_controller(key) -> entity|nil

Resolves event player field as a controller.

Event Example 
register_callback("player_hurt", function(event)
    local attacker = event:get_player_controller("attacker")
    local victim = event:get_player_pawn("userid")
    local dmg = event:get_int("dmg_health")

    if attacker and attacker:is_valid() and victim and victim:is_valid() then
        antikira.log(("%s hurt %s for %d"):format(
            attacker:get_name(),
            victim:get_name(),
            dmg
        ))
    end
end)
